## Znalezione bugi

### P1 — blokujące wartość produktu

**B-1. Chat AI nie wyświetla odpowiedzi (flagowa funkcja Pro martwa w UI)**
API `/api/ai/business/chat` zwraca 200 (AI SDK 5 `toUIMessageStreamResponse()`), ale dymek odpowiedzi jest pusty — jest timestamp, brak treści.
Przyczyna: parser streamu w hookach oczekuje `{"type":"text","text":"..."}`, a AI SDK 5 emituje `{"type":"text-delta","delta":"..."}` (+ `text-start`/`text-end`).
Dotyczy 3 plików: `src/app/dashboard/ai-assistant/business/_hooks/use-business-chat.ts`, `.../trends/_hooks/use-trends-chat.ts`, `src/app/(site)/chat/page.tsx`.
_Notka 2026-11-15: strona `src/app/(site)/chat/` i trasa `/api/chat` zostały usunięte (decyzja PO 2026-11-15)._
**Fix:** obsłużyć `text-delta`/`delta` w parserze (lub przejść na `useChat` z `@ai-sdk/react`). Test: mock streamu w formacie SDK 5.

**B-2. Generator banerów martwy — model Imagen wycofany**
`POST /api/ai/image/banner` → 500; Google zwraca 404: `models/imagen-3.0-generate-002 is not found`. Model już nie istnieje w API — dotyczy też produkcji.
**Fix:** zaktualizować nazwę modelu w `src/lib/ai/google-imagen.ts` do aktualnej wersji Imagen (sprawdzić `ModelService.ListModels`); dodać test kontraktowy/health-check modeli AI.

**B-3. Ciche błędy w UI (409 i 500 bez komunikatu)**
- Konflikt terminu (409) w dialogu "Nowa wizyta": klik "Utwórz wizytę" → nic się nie dzieje, zero komunikatu.
- Błąd generowania banera (500): UI wraca do stanu wyjściowego bez informacji.
**Fix:** toast/inline error w obu miejscach (`getUserFriendlyMessage` już istnieje w libie). To jest punkt "Obsługa błędów w endpointach AI" z Known Issues — problem jest po stronie UI.

### P2 — logika biznesowa / zaufanie do danych

**B-4. Panel nie waliduje grafików pracowników**
Wizyta 20:00–21:00 przy grafiku Anny do 17:00 → 201 bez ostrzeżenia; pracownik bez zapisanego grafiku też przyjmuje wizyty. Jeśli owner-override jest zamierzony — potrzebne ostrzeżenie/confirm ("Poza godzinami pracy — kontynuować?").

**B-5. Wizard rezerwacji oferuje i przyjmuje sloty z przeszłości**
O 11:34 słoty 09:00–11:00 na dziś były klikalne; rezerwacja na 09:00 przeszła (201). Fix: filtrować sloty < now (+bufor) po stronie API available-slots i UI.

**B-6. Stale listy po dodaniu rekordu (usługi, klienci)**
Toast "dodano", ale lista o 1 w tyle do przeładowania (refetch wyścig z POST). Magazyn działa poprawnie — wyrównać wzorzec (await POST → refetch, albo optimistic update jak w products).

**B-7. Luka onboardingu: świeży salon niewidoczny dla klientów bez żadnej informacji**
Rejestracja nie zbiera nazwy/adresu/telefonu salonu (powstaje "Salon <imię>"). `/api/salons` filtruje salony bez adresu i telefonu → nowy salon nie istnieje w portalu klienta, a właściciel nie ma o tym żadnej wskazówki. Dodatkowo newsletter AI wstawia `[numer telefonu] [adres salonu]`.
**Fix:** checklist onboardingowy na dashboardzie ("Uzupełnij profil, aby klienci Cię znaleźli") lub krok "dane salonu" w rejestracji.

### P3 — jakość / higiena

**B-8. `/employees/add` poza layoutem dashboardu** — landing header/footer; "Anuluj" i redirect po zapisie → `/calendar/all` zamiast `/dashboard/employees`. Przenieść pod `/dashboard/employees/add`.

**B-9. Licznik zużycia AI = 0** mimo wywołań (chat 17 s, newsletter, banner) — `/dashboard/ai-usage` pokazuje 0 zapytań / $0.00. Tracking nie obejmuje tych endpointów.

**B-10. Hydration mismatch nonce** — JSON-LD `<script>` w root layout: server ma nonce, klient pusty string. Console error na każdej stronie.

**B-11. Szum CSP w dev** — style-src bez `unsafe-inline`/nonce dla dev-tools → ~20 błędów konsoli na stronę + blokada `eval()` React DevTools. Utrudnia debugging; rozważyć poluzowanie CSP wyłącznie w dev.

### Infrastruktura / ryzyko

**B-12. `.env.local` wskazuje współdzieloną bazę Neon zamiast lokalnego Dockera**
`POSTGRES_URL` = Neon (31 salonów, 34 userów). Lokalny dev (i ten test) pisze do zdalnej współdzielonej bazy; docker-compose Postgres stoi bezużyteczny. Ryzyko: przypadkowe zniszczenie wspólnych danych, testy zanieczyszczają bazę.
**Fix:** lokalny connection string w `.env.local`, Neon tylko przez zmienne Vercela.
